## Sala: Introductory Networking

### Módulo 2: El Modelo OSI (7 Capas)
El modelo OSI describe cómo viajan los datos a través de una red dividiendo el proceso en 7 capas:

7. **Aplicación:** Interfaz con el usuario (ej. HTTP, HTTPS, DNS).
6. **Presentación:** Formato de datos y cifrado.
5. **Sesión:** Mantenimiento de la conexión abierta.
4. **Transporte:** Envío de datos mediante TCP (seguro) o UDP (rápido).
3. **Red:** Direccionamiento lógico e itinerario (Direcciones IP y Routers).
2. **Enlace de Datos:** Direccionamiento físico (Direcciones MAC y Switches).
1. **Física:** Transmisión de señales por cables, Wi-Fi o impulsos.
